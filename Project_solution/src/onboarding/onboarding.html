Your browser asks you to allow Mothlight on these AI sites: ChatGPT, Claude, Gemini, Copilot, Perplexity, Mistral, DeepSeek and Grok. Mo uses this to notice that a prompt was sent, never what you wrote, and to show a small badge with today's total.

Allowed. You're all set.

What Mothlight can see

Site names

Only the hostname of the active tab, like docs.google.com. Not the page, the path or the title.

Whether you're active

The browser tells us "active", "idle" or "locked". We never see what you click or type.

That a prompt was sent

The address a chat request goes to, on AI sites only. The text of your prompt is never read.

Stored only here

In this browser's extension storage. Export or delete everything in one click, any time.

Get started

  1. Pin Mothlight: click the puzzle-piece icon in the toolbar, then the pin next to Mothlight.
  2. Browse as usual. Time only counts while you're active and the browser is in focus.
  3. Open the popup any time to see today, your AI footprint, and your week.
